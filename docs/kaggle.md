# Kaggle

Mã bootstrap và worker OFFLINE nằm trong `src/offline/kaggle/`; package được
sinh vào `build/kaggle` bằng `run.bat kaggle`. Bundle giữ nguyên cấu trúc này,
vì vậy notebook dùng các đường dẫn `src/offline/kaggle/...` sau khi giải nén.

Xem [pipeline OFFLINE](kaggle/guide.md) và [ONLINE backend từ xa](kaggle/online-backend.md).
